## 🤝 Contributing to Documentation

When updating documentation:

1. **Identify the right guide** - Use the audience table above
2. **Update in one place** - Avoid duplicating information
3. **Update version dates** - Maintain "Last Updated" timestamps
4. **Test all links** - Ensure internal links work
5. **Get review** - Documentation PRs need approval
